# OhmLine Électricité

Site vitrine de Thibaut OhmLine Électricité, artisan électricien à Scharrachbergheim-Irmstett (Alsace).

- `index.html` : page d'accueil + formulaire de devis (`index.html#devis`)
- `realisations.html` : galerie photos des chantiers
- `elax.html` : page partenaire Elax
- `style.css` : styles communs, `common.js` : script des pages intérieures
- `assets/` : logo, photos

Les réglages de l'accueil (téléphone, e-mail, Facebook, photos…) sont regroupés dans l'objet `SITE` en bas de `index.html`.
